BOXING PAGE IMAGES
==================

Drop your boxing photos in THIS folder using these exact file names
(or change the names in src/data/BoxingPageData.json to match yours):

  hero.jpg        -> big hero photo at the top of the /boxing page
  gallery-1.jpg   -> photo gallery
  gallery-2.jpg
  gallery-3.jpg
  gallery-4.jpg
  gallery-5.jpg
  gallery-6.jpg

Recommended sizes:
  hero.jpg     ~ 900 x 1100 px (portrait) or 1200 x 900 px
  gallery-*    ~ 800 x 600 px (landscape 4:3)

Until you add these files, the page shows a placeholder image instead
of a broken image, so nothing looks broken.
